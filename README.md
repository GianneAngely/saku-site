# 🌸 Saku site

The **home page, privacy policy and terms of use** for Saku, a free notch app for macOS. Plain HTML and CSS in English and Bahasa Indonesia, served by GitHub Pages.

![Saku site home page](screenshot.png)

## Try it

Open https://gianneangely.github.io/saku-site/ once GitHub Pages is on.

## Run locally

```bash
git clone https://github.com/GianneAngely/saku-site.git
cd saku-site
python3 -m http.server 8000
```

Then open http://localhost:8000.

## What's inside

- **index.html** — what Saku does and how it uses Google Tasks
- **privacy.html** — the privacy policy that Saku's Google sign-in screen links to
- **terms.html** — terms of use
- **id/** — the same three pages in Bahasa Indonesia
- **assets/** — one stylesheet, the app icon and two screenshots

## Built with

HTML · CSS. No scripts, no web fonts and no trackers, so the privacy policy holds for the site too.
